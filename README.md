# CULLNO

大量の TGA / PNG 画像から素早くベストショットを選別するデスクトップツール。

## 特徴

- **連射検出** — 連番ファイルを自動グルーピング、展開して比較
- **高速サムネイル** — Sharp + Worker によるバックグラウンド生成・キャッシュ
- **TGA 対応** — 自前デコーダで TGA を直接読み込み
- **ピック & 削除** — 金色枠で残す写真をマーク。未ピックの写真を一括で確認し、元フォルダ内の trash/ へ移動
- **エクスポート** — ピック済み画像を任意フォルダにコピー
- **比較ビュー** — 2枚並べて拡大・パン同期で細部を比較
- **キーバインドカスタマイズ** — ほぼ全操作のショートカットを変更可能
- **テーマ切替** — ダーク / ライトモード
- **UI スケール** — 80% 〜 150% で調整可能
- **ホーム背景画像** — お好みの画像を Welcome 画面の背景に設定

## v0.3.0 の操作

- プレビューの左右端をタップ・クリックすると前後の写真へ移動。中央はピック切り替え。
- 削除確認は最初に「削除」を選択。←でキャンセル、→で削除、Enterで実行、Escapeで閉じる。
- 「未ピックを削除」は、開いているフォルダ内（子フォルダを含む）の金色枠のない写真が対象。アクティブ選択・表示フィルター・連写の折り畳みには左右されない。確認後に追加された写真は含めない。
- 削除は trash/ への移動。成功後は、移動済みファイルを一覧に復活させないためUndo履歴をクリアする。復元は trash/ から手動で行う。
- 連写はグリッドの写真外ラベルと境界線、プレビュー上部のグループ内位置で確認。隣接する別の連写を一つの枠にまとめない。
- 設定 → プレビュー画質で標準1920px・高精細2560px（QHD）・3840px（4K）を選択。幅の上限であり、元画像より拡大しない。出力画像の解像度には影響しない。

## 技術スタック

- Electron 44 + Vite 8
- React 18 + Fluent UI v9
- Zustand 5（状態管理）
- Sharp（サムネイル生成）

## インストール

[Releases](https://github.com/Yzhav/CULLNO/releases) から zip をダウンロードし、展開して `Cullno.exe` を実行してください。

## 開発

```bash
npm install
npm run dev     # 開発サーバー起動
npm test        # 削除・連写・画質の回帰チェック
npm run build   # プロダクションビルド（release/ に zip 出力）
```

開発版の設定・選別状態はプロジェクト内の .local/dev-data/ に保存され、通常起動の業務データとは分離されます。
